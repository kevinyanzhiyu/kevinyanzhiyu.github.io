02 / ABOUT

闫志瑜
GAME UX DESIGNER

我有近 6 年游戏 UX 设计经验，专注系统玩法、信息架构与交互优化。长期参与《猿族时代》的上线与运营，也负责 Shelter Check 前期避难所经营玩法的 UX 设计。

从方案到 UI、Unity UGUI 落地与实机验证，我持续跟进设计的实际表现。曾任 UX 设计组长，也参与跨职能流程改进与设计师培养。

我如何推进设计

01 / INTERACTION

让复杂系统更容易使用

先梳理信息与操作路径，再决定界面如何呈现。复用玩家熟悉的交互习惯，减少不必要的步骤，让复杂功能更容易理解和使用。

02 / DELIVERY

在实机中验证设计

进入 Unity 检查操作、状态与反馈，而不只看静态设计稿。与主策协作精简审核、前置验收，让问题更早被发现，为修正留出时间。

03 / COLLABORATION

让方法与工具被团队复用

借助 AI 将重复制作整理成 Unity 工具，供设计、策划和客户端同学复用。也帮助设计师拓展 UX 与 UGUI 能力，从单一环节走向独立交付。
